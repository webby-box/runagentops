# Daily Agent Standup — free one-pager

**From:** [@runagentops](https://x.com/runagentops)  
**Use:** one human-led standup per working day your agents are live  
**Time:** ~10 minutes  
**Rule:** paths over vibes. Empty table + claimed progress = theater. Reset the mission.

This is the daily rhythm sheet only. Want the fuller pack later? DM [@runagentops](https://x.com/runagentops) on X — human replies, no spam.

## Anti-patterns (cut these)

- “Making progress” with no path
- Spawning a new agent mid-standup
- Three missions in parallel
- Status updates longer than the work
